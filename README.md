# C++ Learning Journey 🚀

This repository contains all the C++ code I have written during my learning process. Initially, it includes exercises from the **6-hour C++ tutorial** ([intro](https://github.com/LoqmanSamani/cpp/tree/systembiology/intro)) on YouTube ([Course Link](https://www.youtube.com/watch?v=-TkoO8Z07hI)). Now, I have added **10 intermediate-level C++ projects** to solidify my understanding of the language.

## 🚀 How to Run the Projects
1. Clone the repository:
   ```sh
   git clone https://github.com/LoqmanSamani/cpp.git
   cd cpp/projs/
   ```

2. Compile and run any project:
    ```sh
    g++ project_name.cpp -o project_name
    ./project_name
